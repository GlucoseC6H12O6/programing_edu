# 프로그래밍 기초 레슨 학습자용 원고

이 디렉터리의 문서는 “페이지에 무엇을 넣을까?”를 적은 체크리스트가 아니다. 프로그래밍을 한 번도 배우지 않은 사람이 위에서부터 읽고, 코드를 실행해 보고, 문제를 풀 수 있도록 작성한 **실제 페이지 원고 초안**이다.

## 읽는 방법

각 레슨은 같은 순서로 진행한다.

1. **왜 배우나요?**에서 문법이 필요한 상황을 이해한다.
2. **먼저 알아둘 말**에서 새 용어를 확인한다.
3. **가장 작은 예제**를 한 줄씩 읽는다.
4. 실행하기 전에 **먼저 예상해 보기**에 답한다.
5. **한 단계씩 따라가기**에서 값이 변하는 순서를 확인한다.
6. **자주 하는 실수**에서 잘못된 코드가 왜 잘못됐는지 비교한다.
7. **직접 해보기**를 수정해 실행한다.
8. **확인 문제**를 풀고 접힌 정답 해설로 스스로 확인한다.

정답을 먼저 읽어도 괜찮다. 중요한 것은 정답을 외우는 것이 아니라 “왜 그런 결과가 나왔는지” 자기 말로 설명하는 것이다.

## 페이지에 옮길 때의 규칙

- 처음 등장하는 용어는 바로 옆에서 쉬운 말로 설명한다.
- 코드 아래에는 반드시 실제 출력 또는 최종 상태를 보여준다.
- 실행표에는 한 행에 한 가지 변화만 적는다.
- 오답에는 “틀렸습니다”만 표시하지 않고, 컴퓨터가 그 코드를 어떻게 읽었는지 설명한다.
- 확인 문제의 정답은 기본적으로 접어 두되 언제든 펼쳐 볼 수 있어야 한다.
- 단계 실행기 앞에는 관찰할 값을 알려 주고, 뒤에는 관찰 결과를 문장으로 정리한다.
- Python과 JavaScript를 비교할 때에는 우열이 아니라 같은 개념의 표현 차이를 보여준다.

## 원고 완성 판단 기준

학습자가 해당 레슨을 마친 뒤 다음 네 문장을 자기 말로 완성할 수 있어야 한다.

- “이 문법은 ___할 때 사용한다.”
- “컴퓨터는 이 코드를 ___ 순서로 실행한다.”
- “이 값을 바꾸면 결과가 ___로 바뀐다.”
- “이 실수는 ___ 때문에 발생하고, ___로 고친다.”
