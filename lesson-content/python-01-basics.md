## P01. 출력과 주석

### 이번 레슨이 끝나면

`print()`로 문자와 값을 화면에 보여 줄 수 있고, 코드와 출력 결과를 구분할 수 있다. 또한 `#` 뒤의 내용이 컴퓨터가 아니라 사람을 위한 메모라는 것을 설명할 수 있다.

### 왜 배우나요?

프로그램 안의 값은 저절로 화면에 나타나지 않는다. 계산이 제대로 되었는지 확인하거나 사용자에게 결과를 알려 주려면 **출력**해야 한다. `print()`는 값을 보이게 할 뿐 값을 저장하지는 않는다.

### 먼저 알아둘 말

| 용어 | 뜻 |
|---|---|
| 함수 | 미리 정해 둔 일을 수행하는 코드 묶음 |
| 인수 | 함수에게 일을 시킬 때 괄호 안에 전달하는 값 |
| 문자열 | 글자를 따옴표로 감싼 값 |
| 주석 | 사람이 읽는 설명. Python은 실행하지 않는다. |

### 가장 작은 예제

```python
lot_id = "LOT-A01"
print("Lot:", lot_id)
```

두 번째 줄을 조각내 보면 다음과 같다.

- `print`는 “괄호 안의 값을 출력하라”는 함수다.
- `"Lot:"`은 따옴표로 감쌌으므로 글자 그대로의 문자열이다.
- `lot_id`에는 첫 줄에서 저장한 `"LOT-A01"`이 들어 있다.
- 쉼표는 두 값을 구분한다. `print()`는 출력할 때 두 값 사이에 공백 하나를 넣는다.

실제 출력은 다음과 같다. 따옴표와 쉼표는 코드 문법이므로 출력되지 않는다.

```text
Lot: LOT-A01
```

### 먼저 예상해 보기

```python
wafer_id = "W01"
measurement = 94.2
print(wafer_id, measurement, "nm")
```

다음 중 실제 출력은 무엇일까?

1. `"W01", 94.2, "nm"`
2. `W01 94.2 nm`
3. `wafer_id measurement nm`

정답을 고른 뒤 단계 실행에서 문자열과 변수 값이 출력 패널로 이동하는 모습을 확인한다.

### 한 단계씩 따라가기

| 순서 | 실행한 코드 | 일어난 일 |
|---:|---|---|
| 1 | `wafer_id = "W01"` | `wafer_id`라는 이름에 문자열 `"W01"`을 저장한다. |
| 2 | `measurement = 94.2` | `measurement`에 숫자 `94.2`를 저장한다. |
| 3 | `print(...)` | 변수 이름 대신 현재 값을 읽어 `W01 94.2 nm`을 출력한다. |
| 4 | `# print(...)` | `#` 뒤이므로 실행하지 않고 다음 줄로 간다. |

### 자주 하는 실수

```python
print(W01)       # 잘못된 코드
print("W01")     # 올바른 코드
```

첫 번째 코드는 `W01`이라는 **변수 이름**을 찾는다. 그런 변수를 만든 적이 없으므로 `NameError`가 발생한다. 글자 W01 자체를 출력하려면 두 번째 코드처럼 따옴표로 감싸야 한다.

```python
result = print("완료")
print(result)
```

첫 줄은 `완료`를 출력하지만 `print()`는 사용할 결과값을 돌려주지 않는다. 따라서 `result`에는 `None`이 들어간다. “보여 주기”와 “값을 돌려주기”는 다른 일이다.

### 직접 해보기

```python

```

<details>

## P02. 변수, 할당, 기본 타입

### 이번 레슨이 끝나면

값을 변수에 저장하고 다시 할당할 수 있다. 숫자, 문자열, 참·거짓, 값 없음의 차이를 구분하고 상황에 맞는 타입을 선택할 수 있다.

### 왜 배우나요?

프로그램에서 같은 값을 여러 번 사용하려면 기억할 방법이 필요하다. 변수는 값에 붙이는 **이름표**다. `wafer_count`라는 이름을 사용하면 숫자 25가 무엇을 뜻하는지도 함께 드러난다.

### 먼저 알아둘 말

| 타입 | 예 | 의미 |
|---|---|---|
| `int` | `25` | 소수점 없는 정수 |
| `float` | `23.5` | 소수점이 있는 수 |
| `str` | `"EQ-01"` | 글자들의 묶음 |
| `bool` | `True`, `False` | 참 또는 거짓 |
| `None` | `None` | 값이 아직 없음을 나타내는 특별한 값 |

### 할당은 오른쪽부터 실행된다

```python
wafer_count = 25
```

컴퓨터는 먼저 오른쪽의 `25`를 만든다. 그다음 왼쪽의 `wafer_count`라는 이름을 그 값에 붙인다. `=`는 수학의 “양쪽이 같다”가 아니라 “오른쪽 값을 왼쪽 이름에 연결하라”는 **할당** 기호다.

```python
retry_count = 0
retry_count = retry_count + 1
```

두 번째 줄도 오른쪽부터 읽는다. 현재 `retry_count`의 값 0을 읽고 1을 더해 새 값 1을 만든 다음, 같은 이름을 새 값에 다시 연결한다.

### 먼저 예상해 보기

```python
status = "IDLE"
status = "RUNNING"
print(status)
```

`IDLE`과 `RUNNING` 중 무엇이 출력될까? 이전 값이 자동으로 보관되는지도 생각해 본다.

### 한 단계씩 따라가기

| 순서 | 변수 상태 | 설명 |
|---:|---|---|
| 시작 | 이름 없음 | 아직 변수를 만들지 않았다. |
| 1 | `status → "IDLE"` | 첫 값에 이름표를 붙였다. |
| 2 | `status → "RUNNING"` | 이름표가 새 값으로 이동했다. |
| 3 | 출력 `RUNNING` | 이름이 현재 가리키는 값을 읽었다. |

재할당은 이전 값의 기록을 자동으로 남기지 않는다. 기록이 필요하다면 다른 변수에 직접 저장해야 한다.

### 타입이 중요한 이유

```python
count_number = 25
count_text = "25"
```

겉으로는 둘 다 25처럼 보이지만 첫 번째는 계산 가능한 숫자이고 두 번째는 문자 두 개 `"2"`, `"5"`의 묶음이다.

```python
print(count_number + 1)  # 26
print(count_text + "1") # 251
```

### 자주 하는 실수

- `True`와 `"True"`는 다르다. 전자는 참·거짓 값이고 후자는 네 글자의 문자열이다.
- `none`, `NONE`, `Null`은 Python의 값 없음이 아니다. 정확히 `None`이라고 쓴다.
- 변수를 사용하기 전에 값을 할당하지 않으면 `NameError`가 발생한다.

### 직접 해보기

아래 정보에 맞는 타입으로 값을 저장한다.

```python
equipment = ____       # EQ-02
wafer_count = ____     # 25장
temperature = ____     # 23.5도
is_running = ____      # 가동 중
last_error = ____      # 아직 오류 없음
```

그다음 `wafer_count = wafer_count - 1`을 실행하기 전과 후의 값을 예상한다.

3. 바뀌지 않을 Equipment 이름과 계속 바뀌는 측정 횟수도 Python에서는 같은 할당 문법을 쓰는가?

## P03. 숫자와 산술 연산자

### 이번 레슨이 끝나면

사칙연산과 몫·나머지·거듭제곱을 사용할 수 있고, 괄호와 연산 우선순위에 따라 계산 결과가 달라지는 이유를 설명할 수 있다.

### 왜 배우나요?

measurement 평균, 기준과의 편차, Wafer를 몇 묶음으로 나눌 수 있는지처럼 숫자 데이터는 목적에 따라 계산 방법이 다르다. 특히 `/`, `//`, `%`는 모두 나눗셈과 관련 있지만 돌려주는 결과가 다르다.

### 연산자 알아보기

| 코드 | 이름 | `25`와 `4`의 결과 |
|---|---|---:|
| `25 + 4` | 더하기 | `29` |
| `25 - 4` | 빼기 | `21` |
| `25 * 4` | 곱하기 | `100` |
| `25 / 4` | 나누기 | `6.25` |
| `25 // 4` | 몫 | `6` |
| `25 % 4` | 나머지 | `1` |
| `4 ** 2` | 거듭제곱 | `16` |

25장을 4장씩 완전한 묶음으로 만들면 6묶음을 만들고 1장이 남는다. 그래서 `25 // 4`는 6이고 `25 % 4`는 1이다.

### 계산 순서

```python
without_parens = 90 + 10 * 2
with_parens = (90 + 10) * 2
```

Python은 무조건 왼쪽부터 계산하지 않는다. 괄호가 가장 먼저이고, 곱셈·나눗셈이 덧셈·뺄셈보다 먼저다.

| 식 | 첫 계산 | 결과 |
|---|---|---:|
| `90 + 10 * 2` | `10 * 2` | `110` |
| `(90 + 10) * 2` | `90 + 10` | `200` |

### 먼저 예상해 보기

```python
total = 95 + 97 + 93
average = total / 3
full_groups = 25 // 4
remainder = 25 % 4
```

네 변수의 최종값을 종이에 적은 뒤 실행한다.

### 부동소수점은 근삿값이다

```python
print(0.1 + 0.2)
```

결과는 보통 `0.30000000000000004`다. 컴퓨터는 많은 소수를 2진수로 정확히 표현할 수 없어 가까운 값을 저장한다. 초보 단계에서는 “소수 계산 결과에는 아주 작은 오차가 있을 수 있다”는 점을 알고, 화면 표시에는 반올림을 사용하면 충분하다.

### 자주 하는 실수

```python
average = 95 + 97 + 93 / 3      # 의도와 다름
average = (95 + 97 + 93) / 3    # 합계를 먼저 계산
```

첫 코드는 `93 / 3`만 먼저 계산한다. 여러 수의 평균은 합계 전체를 괄호로 묶어야 한다.

또 `25 / 4`에서 정수 6만 얻고 싶다면 `/`가 아니라 `//`를 사용한다. 나머지를 알고 싶다면 `%`를 사용한다.

### 직접 해보기

Wafer 25장을 한 묶음에 6장씩 담는다.

```python

group_size = 6
full_groups = ____
remainder = ____
```

완전한 묶음 수와 남는 Wafer 수를 코드로 완성한다.

3. 17개를 5개씩 묶을 때 몫과 나머지는 무엇인가?

<details>

3. `17 // 5`는 3, `17 % 5`는 2다.

## P04. 문자열과 포매팅

### 이번 레슨이 끝나면

문자열의 특정 글자나 범위를 꺼내고, 공백·대소문자를 정리하며, f-string으로 값이 들어간 문장을 만들 수 있다.

### 왜 배우나요?

현실의 입력은 `"  eq-01  "`처럼 불필요한 공백이나 일정하지 않은 대소문자를 포함할 수 있다. 또 `WAFER-07`에서 앞부분과 번호만 따로 필요할 수도 있다. 문자열은 글자들이 **순서대로 놓인 값**이므로 위치를 이용해 다룬다.

### 인덱스와 슬라이스

문자열 `WAFER-07`의 위치는 다음과 같다.

```text
글자:   W  A  F  E  R  -  0  7
인덱스: 0  1  2  3  4  5  6  7
음수:  -8 -7 -6 -5 -4 -3 -2 -1
```

```python
wafer_id = "WAFER-07"
first = wafer_id[0]       # "W"
prefix = wafer_id[:5]     # "WAFER"
number = wafer_id[-2:]    # "07"
```

슬라이스 `[시작:끝]`은 시작 위치는 포함하지만 끝 위치는 포함하지 않는다. `[:5]`는 0~4번 글자를 가져온다.

### 문자열 메서드는 새 값을 만든다

```python
raw = "  eq-01  "
cleaned = raw.strip()
upper = cleaned.upper()
```

문자열은 만들어진 뒤 내부 글자를 직접 바꿀 수 없다. `strip()`과 `upper()`는 원본을 고치는 대신 **새 문자열을 반환**한다. 따라서 결과를 사용하려면 변수에 저장하거나 바로 다음 메서드와 연결한다.

```python
normalized = raw.strip().upper()  # "EQ-01"
```

### f-string으로 문장 만들기

```python
wafer_id = "WAFER-07"
measurement = 94.234
message = f"{wafer_id}: measurement={measurement:.1f}"
```

`f`가 붙은 문자열의 `{}` 안에는 변수나 식을 쓸 수 있다. `:.1f`는 소수점 아래 한 자리까지 표시한다. 결과는 `WAFER-07: measurement=94.2`다.

### 먼저 예상해 보기

`wafer_id = "WAFER-07"`일 때 다음 세 값은 무엇인지 적어 본다.

```python
wafer_id[1]
wafer_id[1:4]
wafer_id[-1]
```

### 자주 하는 실수

```python
raw.strip()
print(raw)       # 원본에는 여전히 공백이 있다.
```

결과를 저장하지 않았기 때문이다. `raw = raw.strip()`처럼 다시 할당한다.

```python
message = "measurement=" + 94.2  # TypeError
message = f"measurement={94.2}"  # 올바른 방법
```

Python은 문자열과 숫자를 `+`로 바로 더하지 않는다. 숫자를 `str()`로 바꾸거나 f-string을 사용한다.

### 직접 해보기

`"  wafer-12  "`를 `"WAFER_12"`로 바꾼다. `strip()`, `upper()`, `replace()`를 차례로 연결해 본다.

3. `value.upper()`만 실행했는데 `value`가 그대로인 이유는 무엇인가?

<details>
<summary>정답과 해설</summary>

1. `"A"`, `"C"`다.
2. 포함되지 않는다. 슬라이스의 끝 위치는 제외한다.
3. 문자열 메서드는 원본을 수정하지 않고 새 문자열을 반환하기 때문이다.
4. 예상 문제: `"A"`, `"AFE"`, `"7"`이다.
5. 직접 해보기: `raw.strip().upper().replace("-", "_")`로 만들 수 있다.

</details>

## P05. 비교, 불리언, 논리 연산자

### 이번 레슨이 끝나면

비교 결과를 `True` 또는 `False`로 만들고, 여러 조건을 `and`, `or`, `not`으로 결합할 수 있다. 단축 평가 때문에 일부 조건이 실행되지 않을 수 있음을 설명할 수 있다.

### 왜 배우나요?

measurement가 허용 범위에 있는지 확인하려면 하한 이상인지와 상한 이하인지 둘 다 검사해야 한다. 컴퓨터는 이런 질문의 답을 **Boolean**, 즉 참 또는 거짓 값으로 표현한다.

### 비교식도 값을 만든다

```python
measurement = 94.2
above_lower = measurement >= 90.0
below_upper = measurement <= 100.0
```

`measurement >= 90.0`은 명령의 일부가 아니라 결과값 `True`를 만드는 식이다. 그래서 결과를 변수에 저장하고 출력하거나 다른 조건과 결합할 수 있다.

| 연산자 | 의미 | 예 |
|---|---|---|
| `==` | 값이 같다 | `status == "PASS"` |
| `!=` | 값이 다르다 | `count != 0` |
| `<`, `<=` | 작다, 작거나 같다 | `value <= 100` |
| `>`, `>=` | 크다, 크거나 같다 | `value >= 90` |

### 조건 결합하기

```python
in_range = above_lower and below_upper
needs_review = not in_range
```

- `A and B`: 둘 다 참이어야 참이다.
- `A or B`: 둘 중 하나라도 참이면 참이다.
- `not A`: 참과 거짓을 뒤집는다.

### 먼저 예상해 보기

| measurement | `>= 90.0` | `<= 100.0` | 둘을 `and`한 결과 |
|---:|---|---|---|
| 89.9 | ? | ? | ? |
| 90.0 | ? | ? | ? |
| 100.0 | ? | ? | ? |
| 100.1 | ? | ? | ? |

경계에 있는 90.0과 100.0이 포함되는지 주의한다.

### 단축 평가

```python
lot_id = ""
wafer_count = 0
is_empty = lot_id == "" or wafer_count == 0
```

`or`는 왼쪽이 이미 참이면 전체 결과가 참으로 결정된다. 따라서 오른쪽은 확인할 필요가 없어 실행하지 않는다. `and`는 왼쪽이 거짓이면 전체가 거짓으로 결정되어 오른쪽을 실행하지 않는다. 이것이 **단축 평가**다.

### 자주 하는 실수

```python
measurement = 94.2       # 값을 저장
measurement == 94.2      # 두 값을 비교
```

`=`와 `==`는 역할이 다르다.

```python
in_range = measurement >= 90 or measurement <= 100  # 거의 항상 참
in_range = measurement >= 90 and measurement <= 100 # 두 경계를 모두 통과
```

범위 안이라는 뜻은 하한 조건과 상한 조건을 **둘 다** 만족해야 하므로 `and`가 필요하다.

### 직접 해보기

`lot_id`와 `wafer_count`를 다음 네 조합으로 바꾸고 `is_ready = lot_id != "" and wafer_count > 0`의 결과를 기록한다.

1. `"LOT-A01"`, `25`
2. `""`, `25`
3. `"LOT-A01"`, `0`
4. `""`, `0`

### 확인 문제

1. `95 >= 90 and 95 <= 100`의 결과는 무엇인가?
2. `not True`의 결과는 무엇인가?
3. 범위 밖이라는 조건을 `measurement < 90 ____ measurement > 100`으로 쓸 때 빈칸에는 무엇이 들어가는가?

<details>
<summary>정답과 해설</summary>

1. 두 비교가 모두 참이므로 `True`다.
2. `False`다.
3. 두 범위 중 하나에만 해당하면 되므로 `or`가 들어간다.
4. 표의 결과는 차례로 `False, True, True, False`다.
5. 직접 해보기의 `is_ready`는 차례로 `True, False, False, False`다.

</details>

## P06. List와 Tuple

### 이번 레슨이 끝나면

여러 값을 List와 Tuple에 저장하고 인덱스로 읽을 수 있다. List는 수정 가능하고 Tuple은 수정할 수 없다는 차이, 두 변수가 같은 List를 가리킬 때 생기는 변화를 설명할 수 있다.

### 왜 배우나요?

Wafer ID가 세 개라면 변수도 세 개 만들 수 있지만, 개수가 늘어날수록 관리하기 어렵다. List는 관련된 값을 순서대로 한 상자에 담는다.

### List의 기본 동작

```python
wafers = ["W01", "W02", "W03"]
wafers.append("W04")
wafers[1] = "W02-R"
```

- 대괄호 `[]`는 List를 만든다.
- 첫 원소의 인덱스는 0이다.
- `append()`는 List 끝에 원소를 추가한다.
- `wafers[1] = ...`은 두 번째 원소를 바꾼다.

최종 List는 `["W01", "W02-R", "W03", "W04"]`다.

### Tuple은 고정된 값 묶음이다

```python
range_limit = (90.0, 100.0)
lower = range_limit[0]
upper = range_limit[1]
```

Tuple은 소괄호로 표현하고 만든 뒤 원소를 바꿀 수 없다. 항상 Tuple만 써야 하는 것은 아니지만, “이 값 묶음은 바꾸지 않는다”는 의도를 나타낼 때 유용하다.

### 변수는 List 상자를 가리킨다

```python
wafers = ["W01", "W02"]
same_list = wafers
copied = list(wafers)
wafers.append("W03")
```

| 변수 | 최종값 | 이유 |
|---|---|---|
| `wafers` | `["W01", "W02", "W03"]` | 원본에 추가했다. |
| `same_list` | `["W01", "W02", "W03"]` | 같은 List 상자를 가리킨다. |
| `copied` | `["W01", "W02"]` | `list()`로 별도 상자를 만들었다. |

`same_list = wafers`는 내용을 복사하지 않는다. 같은 객체에 이름표를 하나 더 붙인다.

### 먼저 예상해 보기

위 코드에서 `same_list[0] = "CHANGED"`를 추가하면 `wafers[0]`은 무엇이 될까? `copied[0]`도 바뀌는지 예상한다.

### 자주 하는 실수

```python
last = wafers[len(wafers)]      # IndexError
last = wafers[len(wafers) - 1]  # 마지막 원소
last = wafers[-1]               # 더 간단한 표현
```

길이가 3이면 유효 인덱스는 0, 1, 2다. `len(wafers)`인 3은 범위를 벗어난다.

```python
result = wafers.append("W04")
```

`append()`는 원본을 직접 바꾸며 새 List를 반환하지 않는다. 따라서 `result`는 `None`이다.

### 직접 해보기

원본을 유지하면서 `"W04"`가 추가된 새 List를 만든다.

```python
wafers = ["W01", "W02", "W03"]
new_wafers = list(wafers)
____
```

### 확인 문제

1. 길이가 4인 List의 마지막 유효 인덱스는 무엇인가?
2. List와 Tuple 중 원소를 바꿀 수 있는 것은 무엇인가?
3. `b = a` 뒤 `b.append(3)`이 `a`에도 보이는 이유는 무엇인가?

<details>
<summary>정답과 해설</summary>

1. 3이다. 인덱스는 0부터 시작한다.
2. List다. Tuple은 생성 후 원소를 바꿀 수 없다.
3. `a`와 `b`가 서로 다른 내용 복사본이 아니라 같은 List 객체를 가리키기 때문이다.
4. 예상 문제에서 `wafers[0]`은 `"CHANGED"`, `copied[0]`은 `"W01"`이다.
5. 직접 해보기의 빈칸은 `new_wafers.append("W04")`다.

</details>

## P07. Dictionary와 Set

### 이번 레슨이 끝나면

Dictionary의 키로 값을 읽고 추가·수정할 수 있다. 없는 키를 안전하게 확인하고, Set으로 중복을 제거하거나 포함 여부를 검사할 수 있다.

### 왜 배우나요?

Wafer 한 장에는 ID, measurement, 판정처럼 서로 의미가 다른 값이 있다. List에 넣으면 `wafer[0]`이 무엇인지 외워야 하지만 Dictionary는 `wafer["measurement"]`처럼 값의 의미를 키에 담는다.

### Dictionary 사용하기

```python
wafer = {
    "id": "W01",
    "measurement": 94.2,
    "passed": True,
}

wafer["measurement"] = 95.1
wafer["retested"] = True
```

기존 키에 할당하면 값을 수정하고, 없던 키에 할당하면 새 키·값 쌍을 추가한다.

```python
print(wafer["id"])            # W01
print(wafer.get("operator"))  # None
```

`[]`로 없는 키를 읽으면 `KeyError`가 발생한다. `.get()`은 키가 없으면 기본적으로 `None`을 반환한다. `.get("operator", "UNKNOWN")`처럼 대신 사용할 기본값도 줄 수 있다.

### Set으로 중복 없애기

```python
equipment_ids = set()
equipment_ids.add("EQ-01")
equipment_ids.add("EQ-02")
equipment_ids.add("EQ-01")
```

같은 값 `"EQ-01"`을 두 번 추가해도 Set에는 한 번만 남는다. 따라서 길이는 2다. Set은 중복 없는 값과 빠른 포함 검사가 중요할 때 사용한다.

```python
print("EQ-02" in equipment_ids)  # True
print("EQ-09" in equipment_ids)  # False
```

### 먼저 예상해 보기

```python
record = {"id": "W01", "value": 94.2}
record["value"] = 95.0
record["status"] = "PASS"
```

최종 키 개수와 각 값을 적어 본다. 어떤 줄은 수정이고 어떤 줄은 추가인지 구분한다.

### 자주 하는 실수

```python
operator = wafer["operator"]            # 없으면 KeyError
operator = wafer.get("operator")        # 없으면 None
operator = wafer.get("operator", "-")   # 없으면 "-"
```

무조건 `.get()`이 더 좋은 것은 아니다. 반드시 있어야 하는 키가 없다면 오류로 발견하는 편이 낫다. 키가 선택 사항일 때 `.get()`이 유용하다.

Set의 출력 순서에 의존해서도 안 된다. Set의 목적은 위치 보존이 아니라 중복 제거와 포함 검사다. 순서가 필요하면 List를 사용한다.

### 직접 해보기

세 Equipment ID `EQ-01`, `EQ-02`, `EQ-01`에서 중복을 제거하고, `EQ-03`이 포함되어 있는지 출력한다. 그다음 Dictionary `wafer`에 선택적 `operator` 값을 추가해 `.get()` 전후를 비교한다.

### 확인 문제

1. Dictionary가 List와 달리 값을 찾는 기준은 무엇인가?
2. 없는 키를 `record["note"]`로 읽으면 어떤 오류가 발생하는가?
3. Set에 같은 값을 세 번 추가하면 그 값은 몇 개 남는가?

<details>
<summary>정답과 해설</summary>

1. 위치 인덱스가 아니라 키를 사용한다.
2. `KeyError`가 발생한다. 선택 항목이면 `.get("note")`를 사용할 수 있다.
3. 한 개만 남는다.
4. 예상 문제의 최종 Dictionary는 `{"id": "W01", "value": 95.0, "status": "PASS"}`이고 키는 3개다. `value`는 수정, `status`는 추가다.

</details>
